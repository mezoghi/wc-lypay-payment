# LYpay Payment Gateway for WooCommerce

A WooCommerce payment gateway plugin that allows customers to pay via LYpay (IBAN transfer).

## Features

- Simple IBAN transfer payment method
- Configurable payment instructions
- WhatsApp and email contact options
- Custom order status settings
- Admin configuration interface

## Installation

1. Download the plugin as a ZIP file
2. In your WordPress admin, go to **Plugins > Add New**
3. Click **Upload Plugin** and select the ZIP file
4. Activate the plugin

## Configuration

1. After activation, go to **WooCommerce > Settings > Payments**
2. Find "LYpay" in the payment gateways list
3. Click **Manage** to configure the settings:
   - **Title**: Payment method title displayed to customers
   - **Description**: Payment method description
   - **Instructions**: Payment instructions shown to customers
   - **IBAN**: Your IBAN account number
   - **WhatsApp**: Your WhatsApp contact number
   - **Email**: Your contact email
   - **Order Status**: Default order status for LYpay payments

## Usage

Once configured, customers will see LYpay as a payment option at checkout. After selecting it, they'll receive payment instructions with your IBAN and contact information.

## Requirements

- WordPress 5.0+
- WooCommerce 3.0+
- PHP 7.4+
